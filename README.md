# دليل تشغيل موقع حازم ستور

الموقع فيه صفحتين:

- **`index.html`**: المتجر للزبائن، وهو الرابط اللي بتنشره وبيطلع على جوجل.
- **`admin.html`**: لوحة التحكم إلك إنت، وجوجل ما بيأرشفها.

## شو بيصير لما زبون يطلب

1. الزبون بيختار الاشتراك والمدة، وممكن يضيف أكثر من اشتراك للسلة.
2. بيختار طريقة الدفع (جوال باي، بال باي، بنك فلسطين، USDT) وبيشوف رقمك `0594826482` واسمك "حازم محسن العشي".
3. لازم يكتب إثبات الحوالة (الرقم أو الاسم اللي حوّل منه) أو يرفع سكرين.
4. بيرسل الطلب على واتساب `+970594826482`، والطلب مع السكرين بيوصل للوحة التحكم.
5. إنت بتأكد الطلب من اللوحة، وبينحسب صافي الربح تلقائياً: سعر البيع ناقص سعر الجملة.

---

## 1) اربط قاعدة البيانات (Firebase، مجاناً)

بدون هالخطوة اللوحة بتشتغل على جهاز واحد بس، وطلبات الزبائن ما بتوصلك عليها.

1. ادخل على https://console.firebase.google.com بحساب جوجل.
2. اضغط **Add project**، وسمّيه `hazem-store`، ووقّف Google Analytics، واضغط Create.
3. فعّل الدخول بالإيميل:
   - من القائمة: **Build ← Authentication ← Get started ← Email/Password**، فعّلها واضغط Save.
   - من تبويب **Users ← Add user**: اكتب إيميلك وكلمة سر قوية. هذا حساب الإدارة تبعك.
   - (مستحسن) من **Settings ← User actions**: شيل علامة *Enable create (sign-up)* عشان ما حدا غيرك يعمل حساب.
4. اعمل قاعدة البيانات: **Build ← Firestore Database ← Create database**، اختار موقع قريب مثل `eur3`، وبعدين **Start in production mode**.
5. بنفس صفحة Firestore افتح تبويب **Rules**، امسح اللي فيه، والصق محتوى ملف `firestore.rules`.
   **مهم:** غيّر `YOUR_ADMIN_EMAIL@gmail.com` لإيميلك، واضغط **Publish**.
6. اضغط ⚙️ **Project settings**، وتحت *Your apps* اضغط أيقونة الويب `</>`، وسمّيه `hazem-store`، واضغط Register.
   بيطلعلك كود فيه `const firebaseConfig = { ... }`. انسخ اللي بين القوسين.
7. عدّل ملف `config.js`:
   - بدّل `firebase: null` بـ `firebase: { ...الكود اللي نسخته... }`
   - واكتب إيميلك مكان `adminEmail: ""`

> إذا صعب تعدّل الملف من الجوال، ابعت كود `firebaseConfig` وإيميلك لـ Claude، وبيرجعلك الملفات جاهزة.

## 2) انشر الموقع على الإنترنت (Netlify، مجاناً)

1. ادخل على https://app.netlify.com/drop
2. ارفع ملف الموقع المضغوط (zip) أو المجلد كامل، وبعد ثواني بيصير عندك رابط.
3. اعمل حساب على Netlify عشان يضل الموقع إلك (Claim / Sign up).
4. من **Site configuration ← Change site name** اكتب `hazem-store`، فبيصير الرابط https://hazem-store.netlify.app
   - إذا الاسم مأخوذ، اختار اسم ثاني، وبدّل الرابط بملفات `index.html` (سطر canonical وسطور og) و`robots.txt` و`sitemap.xml`.
5. ارجع على Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**، وضيف `hazem-store.netlify.app`.
6. افتح `https://hazem-store.netlify.app/admin.html` وادخل بإيميلك وكلمة السر.
   أول دخول بيجهّز المتجر تلقائياً بالاشتراكات والأسعار وطرق الدفع.
7. من **المنتجات** اكتب سعر الجملة لكل مدة، ومن **طرق الدفع** ضيف عنوان محفظة USDT.

لما تعدّل منتجات أو أسعار من اللوحة، ما بتحتاج ترفع الموقع من جديد.

## 3) أيقونة لوحة التحكم على جوالك

افتح `admin.html` على الجوال:

- **آيفون (Safari):** زر المشاركة ← **Add to Home Screen**.
- **أندرويد (Chrome):** القائمة ⋮ ← **Add to Home screen**.

بتظهر أيقونة "إدارة حازم ستور" الرسمية، وبتفتح اللوحة مثل التطبيق.

## 4) أيقونات التطبيقات وطرق الدفع

- كل اشتراك إله حقل **موقع التطبيق الرسمي** (مثل `chatgpt.com` أو `canva.com`)، والموقع بيجيب أيقونته الرسمية تلقائياً.
- طرق الدفع إلها نفس الشي (مثل `jawwalpay.ps` و`palpay.ps` و`bankofpalestine.com`).
- إذا أيقونة ما ظهرت صح، ارفع الشعار بنفسك من زر **رفع صورة** بصفحة التعديل.

## 5) خلي الموقع يظهر على جوجل

1. ادخل على https://search.google.com/search-console، واضغط **Add property**، واختار **URL prefix**، واكتب `https://hazem-store.netlify.app/`
2. اختار طريقة التحقق **HTML tag** وانسخ السطر:
   `<meta name="google-site-verification" content="...">`
3. الصقه بملف `index.html` مكان السطر المكتوب عليه *Google Search Console*. ارفع الموقع من جديد على Netlify (Deploys ← ارفع الملفات)، وارجع لجوجل واضغط **Verify**.
4. من **Sitemaps** اكتب `sitemap.xml` واضغط Submit.
5. من **URL inspection** حط رابط موقعك واضغط **Request indexing**.

الظهور بنتائج البحث بياخد من كم يوم لأسبوعين. لتسريعه:

- حط الرابط بالبايو على إنستغرام وفيسبوك وتيك توك، وبستوري واتساب.
- اعمل ملف نشاط تجاري على جوجل من https://business.google.com باسم "حازم ستور" وحط رابط الموقع.
- (اختياري) دومين خاص مثل `hazemstore.com`، وبتربطه من Netlify ← Domain management.

## ملاحظات أمان

- سعر الجملة والأرباح والطلبات **ما بيشوفها غيرك**. قواعد الحماية بتسمح للزبون يقرأ المنتجات وأسعار البيع ويرسل طلب جديد بس.
- ما تعطي كلمة سر الإدارة لحدا. إذا نسيتها، اضغط "نسيت كلمة السر؟" بصفحة الدخول.
- خذ نسخة احتياطية كل فترة من **الإعدادات ← نسخة احتياطية ← تصدير**.

## الملفات

| الملف | شو هو |
|---|---|
| `index.html` | المتجر |
| `admin.html` | لوحة التحكم |
| `config.js` | ربط قاعدة البيانات وإيميل الإدارة |
| `firestore.rules` | قواعد الحماية، بتلصقها في Firebase |
| `robots.txt` و `sitemap.xml` | لجوجل |
| `og-image.png` | الصورة اللي بتظهر لما ينبعت رابط الموقع |
| `icon-*.png` و `favicon-*.png` و `site.webmanifest` | أيقونات المتجر |
| `admin-icon-*.png` و `admin.webmanifest` | أيقونة لوحة التحكم الرسمية |
